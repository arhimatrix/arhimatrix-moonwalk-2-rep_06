# Moonwalk 2.0 · Report 06

Two robots build it — and three are planned. Every structure replanned for crews of Dragons with Isaac-playable plans on the real Report 04 geometry: the graded pad 9.90 → 3.89 h (2.5×, two placers, half each), the ShellA dome 5.07 → 2.71 h (1.9×, A inside + B outside then hauling), the 2.5 m power column with no lift — the robots reconfigure for height (tandem 2.83 h). Plus the power study: what a column is worth as a function of cell size and sun exposure (lattice ≈ 1.4 kW continuous, ≈ 26 kW per 18-column field). Build films in media/ (720p, browser-uploadable): pad wide · dome wide/follow/arm. Interactive: zoomable plan boards, a play-the-plan scrubber, a live power calculator. Three-robot runs: queued.
